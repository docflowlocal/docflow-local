# Roadmap

The roadmap communicates direction, not a delivery guarantee.

## Community Edition

- High-fidelity DOCX placeholder replacement across XML runs;
- Additional CSV/XLSX import diagnostics;
- Reusable project files for mappings and output rules;
- More deterministic PDF and ZIP validation;
- Signed macOS and Windows releases;
- Community template schema and examples;
- Accessibility and localization improvements.

## Pro

- Visual PDF coordinate and AcroForm designer;
- Visual computed/conditional rule editor;
- Watched folders and scheduled local jobs;
- CLI batch automation;
- Project history, audit reports, and shared template libraries;
- Offline business licensing and priority support.

## Industry solutions

- Trade quotation packages;
- Engineering delivery packages;
- HR onboarding packages;
- Compliance submission packages;
- School certificates and assessments.

Feature requests and design proposals belong in GitHub Discussions.
